# apexkube-company-web

The ApexKube company website (www.apexkube.xyz). A mobile-first static site, generated by Python and Jinja2.

## Build & preview

```bash
source .venv/bin/activate
pip install -r requirements.txt
python build.py          # writes the site to dist/
python serve.py          # builds, then serves on port 8000 (open the Network URL on your iPhone)
```

## Layout

- `content/site.py`: all page copy and lists (services, solutions, FAQs). Edit text here.
- `templates/`: Jinja2 page templates (`base.html` holds the header and footer).
- `static/`: CSS, JS and the logo (`img/logo.svg`).
- `content/touch_icon.py`: renders the iPhone home-screen icon PNG at build time.

To deploy, upload the contents of `dist/` to any static host (GitHub Pages, Netlify, Cloudflare Pages).
